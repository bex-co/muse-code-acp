# Upstream dependencies

Everything this adapter is blocked on or works around because of Muse (host or
SDK) or ACP. One row per upstream item, each linked to the board item that
tracks the adapter side. Status checked **2026-10-26** (adapter 0.11.0, Muse
1.4.13-R6996.1, `@muse-code/sdk` 1.4.12, ACP SDK 1.8.0).

Issues are in [meta-models/muse-code-sdk](https://github.com/meta-models/muse-code-sdk/issues)
unless noted. "Filed by us" means the maintainer account reported it.

How to maintain: re-check open rows on every Muse or SDK bump (`gh issue view <n>
-R meta-models/muse-code-sdk`). When a fix ships, verify it on the real host, remove the
adapter workaround if one exists, and move the row to **Resolved** with the version
and evidence. Board conventions still apply (`.pm/` skills); this file is an index,
not a substitute for the board items it links.
