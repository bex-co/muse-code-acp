## Objective

The adapter runs on `@muse-code/sdk` 1.4.8, with new items and view events classified and the real-host suite passing on Muse 1.4.8.

## Context

## Steps

1. Diff the SDK 1.4.7 → 1.4.8 method registry, schemas and event types.
2. Bump the exact pin.
3. Classify new items and events in `src/muse-sdk-events.ts` / `src/muse-view-events.ts`, with unit tests.
4. Re-probe only features previously left unadvertised whose public method changed in 1.4.8 (for example marketplace or interrupts); record the results. `session/compact` was already re-checked on 1.4.8 (w3/m9 validation evidence, 2026-10-15: unchanged).
5. Run `MUSE_CODE_ACP_REQUIRE_MUSE=1 npm run test:muse-loopback` on 1.4.8.
6. If the w3/m16 newest-host CI leg exists, update it to 1.4.8 with a pinned hash.
