## Objective

`/plugins` and `/hooks` list installed plugins and hooks; plugin install and marketplace changes run only on explicit user commands.

## Context

- Install and marketplace changes modify the user's Muse setup: never automatic, always an explicit command with the exact target echoed, and refused when the host reports `pluginMutationsDisabled`.
- Advertise only what t001 verified; keep explicit unavailability elsewhere.

## Steps

1. Implement the ACP surface (slash command and/or negotiated extension) over the verified methods.
2. Add deterministic tests (fake MSP) and a live test on the installed host, gated so CI's Muse 1.1.1 skips cleanly.

- src/
- src/tests/

## Acceptance criteria

- [ ] Listing commands show host data; install/marketplace commands mutate only on explicit user input, surface host errors (`pluginNotFound`, `marketplaceAlreadyExists`, `pluginMutationsDisabled`) verbatim, and are covered by tests that never touch the real user configuration.
