## Objective

Wire, fake-host and real-host tests prove the negotiated state sequence and the unchanged fallback.

## Context

- Use the fake MSP and wire helpers (`src/tests/acp-wire-helpers.ts`, `src/tests/fake-msp.test.ts`) and the loopback live suites.
- If w3/m16 has landed, gate the live test through its capability helper.

## Steps

1. Wire tests with a negotiating client: approval escalation, user input, cancel during approval, stall-watchdog failure, exec backend.
2. Fallback wire tests with a non-negotiating client.
3. A live loopback test asserting the sequence on the installed host, including that a reviewer-approved call (Muse 1.4.6+) produces no requires-action state.

## Files

- src/tests/
- package.json (`test:muse-loopback` list, if a new live file is added)

- [ ] Negotiated and fallback wire tests pass.
