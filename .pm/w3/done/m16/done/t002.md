## Objective

CI installs the public Muse 1.4.7-R6101.1 Linux build with a pinned SHA-256 and runs the loopback suites with all 1.4.7 capabilities required.

## Context

- `.github/workflows/ci.yml` `muse-loopback` installs 1.1.1-R2514.1 from the public lookaside URL, checks a SHA-256 from Meta's manifest and runs on `ubuntu-22.04` because 1.1.1's bwrap cannot create its loopback namespace under Ubuntu 24.04's default AppArmor policy.
- The 1.4.7-R6101.1 `muse-x86-linux` artifact returned HTTP 200 on 2026-10-15.
- `publish.yml` calls `ci.yml` through `workflow_call`, so release gates inherit the new leg.

## Steps

1. Obtain the 1.4.7 SHA-256 from Meta's public release manifest. If no manifest publishes it, record the hash of the downloaded artifact and how it was obtained.
2. Turn `muse-loopback` into a matrix (version, hash, runner, required capabilities), keeping the 1.1.1 leg unchanged.
3. Run the 1.4.7 leg on `ubuntu-22.04`; evaluate 24.04 only if 22.04 fails. Keep the sandbox enabled.
4. Set the t001 declaration on the 1.4.7 leg.
5. Set a realistic job timeout and record leg durations.

## Files

- .github/workflows/ci.yml

## Acceptance criteria

- [x] Both legs appear in a CI run with distinct names, and each pinned hash is verified by `sha256sum --check`.
- [x] The 1.4.7 leg logs `muse --version` as 1.4.7-R6101.1.
- [x] The release path (`publish.yml`) still runs the same CI workflow.

## Out of scope

- The standalone job's host version; fixing suite failures (t003).

## Evidence

`muse-loopback` is now a matrix over Muse 1.1.1-R2514.1 (unchanged) and 1.4.7-R6101.1 on `ubuntu-22.04`, sandbox enabled, `fail-fast: false`. SHA-256 values come from Meta's public release manifests (`lookaside.facebook.com/lookaside/muse/download/?channel=muse&version=<version>&file=manifest.json`, linked from the public channel manifest `api.meta.ai/muse-code/channels/muse-stable`); the 1.1.1 entries match the hashes CI already pinned. 1.4.7 `x86_linux`: `36e3dac9…c2518`, 363518168 bytes. The 1.4.7 leg sets `MUSE_CODE_ACP_REQUIRE_HOST_FEATURES=all`. CI logs show `/home/runner/work/_temp/muse-code/muse: OK` and `Muse Code 1.4.7 (1.4.7-R6101.1)`. `publish.yml` still calls this same `ci.yml` and gates on its result. Legs take about 1.5 minutes each, well inside the 25-minute timeout.
