## Objective

Evidence for which of turn/interrupt, turn/unqueue (1.3.0), userInput/interrupt (1.4.4), usage/read (1.3.0) the installed host completes, with exact request/response shapes.

## Context

- `docs/capability-audit.md` lists interrupt/unqueue as "public methods exist; not advertised"; ACP cancel maps to `turn/cancel`; `/status` reports usage from folded events.
- Use the loopback provider and isolated directories; no paid tokens.
- Depends on w3/m7 so verification runs on Muse 1.4.6 with SDK 1.4.6.

## Steps

1. Probe each method through the public SDK connection and record outcomes, errors and resulting folded events/items.
2. Record which hosts/versions support each operation and any refusal kinds.

## Files

- Throwaway probe only

## Acceptance criteria

- [x] Per-method outcome table with host version recorded in the milestone validation evidence.

## Out of scope

- Implementing the surface (t002).

## Evidence

Muse 1.4.7-R6101.1, public SDK connection, loopback provider, no paid tokens:

| Method                                                  | Result                                                  | Decision                                              |
| ------------------------------------------------------- | ------------------------------------------------------- | ----------------------------------------------------- |
