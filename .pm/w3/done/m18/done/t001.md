## Objective

Every `prompt()` branch maps to a test that fails if its behavior changes, and the pre-refactor baseline is recorded.

## Context

- Requires the deterministic suite (w3/m15/t001) and working coverage (w3/m15/t003).
- Branches include slash and native commands (`src/slash-commands.ts`, `src/host-commands.ts`; goal, recap, rename, skills, feedback, plugins, hooks, status, tasks), review and plan prompts, SDK turns, exec turns, steering, failure handling (`src/turn-failure.ts`) and cancellation.

## Steps

1. Record baseline unit and loopback counts and line/branch coverage for `src/acp-agent.ts`.
2. Map each `prompt()` branch to the tests that exercise it; record the map in this task's evidence.
3. Add wire or fake-MSP tests for uncovered branches.

Baseline (2026-10-15, after w3/m17): `npm run test:unit` 510/510; Muse 1.4.8 loopback 68/68; `src/acp-agent.ts` 2310 lines, statement-line coverage 81.6% (669/820), `prompt()` 558 lines.

Branch-to-test map for `prompt()`: command parsing and validation (`slash-commands*.test.ts`, `prompt-content.test.ts`); `/rename`, `/skills`, `/logout` (`session-commands-wire.test.ts`, spawned, plus `session-commands-live`); `/models` (`discovered-config.test.ts`); `/tasks` with tasks, task updates, host-owned-turn rejection (`async-tasks-live`); status text (`progress-live`); goal controls (`goal-controls.test.ts`); plan and review workflows (`slash-commands-wire.test.ts`, `workflows-live`); SDK turn streaming, failures, cancellation, steering (`muse-sdk*.test.ts`, `cancellation.test.ts`, `steering-wire.test.ts`, `failure-modes.test.ts`); exec turn, max steps and approval stall (`failure-modes.test.ts`, `exec-approval-stall.test.ts`, `exec-profile-live`).

Added `src/tests/prompt-branches.test.ts` (6 tests) for branches no test reached: `/tasks` without a host; native rename refused by Muse (new `FAKE_MSP_RENAME_REJECT` fixture switch); version-gated commands on a 1.1.1 host send nothing; plan-mode instruction prefix; SDK backend refuses the echo provider; exec usage error. Coverage after: 516/516, `acp-agent.ts` 82.9%.

Left uncovered, with reason: workflow or plan command while a host-owned turn is active, configuration changing during `/models`, MCP changing during plan-host setup, catalog delivery failure, client-provider/saved-provider mismatch (race-only or multi-process setups), and an `unreachable` default. Spawned wire tests are not visible to coverage, so in-process numbers understate behavioral coverage.
