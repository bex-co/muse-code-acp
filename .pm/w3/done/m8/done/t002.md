## Objective

`/goal` sets, edits, pauses, resumes and clears the native Muse goal instead of reporting persistent controls as unavailable.

## Context

- `src/slash-commands.ts` describes `/goal` as "persistent controls unavailable"; `docs/capability-audit.md` row "native goal mutation" says no method exists (audited at SDK 0.1.1); `session/goalChanged` is already folded into the `muse/goal` extension.
- Advertise only what t001 verified; keep explicit unavailability elsewhere.

## Steps

1. Implement the ACP surface (slash command and/or negotiated extension) over the verified methods.
2. Add deterministic tests (fake MSP) and a live test on the installed host, gated so CI's Muse 1.1.1 skips cleanly.

## Files

- src/
- src/tests/

## Acceptance criteria

- [x] `/goal set|edit|pause|resume|clear` call the public methods and the observed goal (via `session/goalChanged`) reflects each change; hosts without the methods keep today's explicit unavailability.

## Evidence

- Parser (`src/slash-commands.ts`): `/goal set|edit <objective>`, `/goal pause|resume|clear` (sent alone) → `goal` command; `/goal <task>` still executes once; `/goal status` unchanged.
- `spawnMuseSdkTurn` (`src/muse-sdk.ts`) `goal` option: sends `goal/<verb>`; with a `turnId` it streams `session.turn(turnId)` through the normal path, otherwise waits for the folded goal change and `owner.flushGoal()` before releasing; Muse refusals become `Muse did not <verb> the goal: <reason>`.
- Agent: controls require the SDK backend and `supportsGoalControls` (Muse ≥ 1.4.6, `src/muse-host.ts`); allowed while a host-owned goal turn runs (`acquire` reuses the host without the unfinished-work refusal); `muse/goal` advertises the controls; `/goal` status text updated.
- Found and fixed: release closed the host while a host-owned turn was still writing after a clear, truncating the log (`MalformedJsonl` on reopen); the host is now kept while a turn runs.
- Tests: `src/tests/goal-controls.test.ts` (fake MSP with per-session goal persistence: full verb flow, refusals, advertisement), parser cases in `slash-commands.test.ts`, live `src/tests/goal-controls-live.test.ts` (4/4 on 1.4.6), `goal-live.test.ts` expectation by host support.
