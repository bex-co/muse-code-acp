## Objective

Evidence for which of skill/setActivation (1.4.4), skill/import (1.4.6), feedback/submit (1.4.4) the installed host completes, with exact request/response shapes.

- Use the loopback provider and isolated directories; no paid tokens.
- Depends on w3/m7 so verification runs on Muse 1.4.6 with SDK 1.4.6.
