## Objective

`npm run test:coverage` measures the deterministic suite and enforces non-regressing thresholds in CI.

## Context

- `package.json` `test:coverage` runs `vitest run --coverage`, but `@vitest/coverage-v8` is not installed, so the script fails immediately.
- `vitest.config.ts` configures the v8 provider without `include` or thresholds.
- `test:unit` excludes `src/tests/**/*-live.test.ts` and `src/tests/real-provider.integration.test.ts`; coverage must use the same exclusions.

## Steps

1. Add `@vitest/coverage-v8` pinned exactly to the installed Vitest version.
2. Make `test:coverage` use the `test:unit` exclusions.
3. Set `coverage.include` to `src/**/*.ts` and exclude `src/tests/**`.
4. Record baseline statement, branch, function and line percentages; set thresholds at the baseline rounded down to whole percents.
5. Run coverage in the CI build job, replacing the `test:unit` step if it is equivalent, so runtime does not double.
6. Make sure `coverage/` is ignored by git and Prettier and excluded from the package.
7. Add `npm run test:coverage` to the README testing command list.

## Files

- package.json, package-lock.json

## Acceptance criteria

- [x] From a clean `npm ci`, `npm run test:coverage` succeeds and prints a summary.
- [x] Baseline percentages are recorded in the milestone validation evidence.
- [x] Dropping coverage below a threshold fails the command (shown with a temporary uncommitted change).
- [x] The CI build job runs it, and `npm pack --dry-run` includes no coverage output.

## Out of scope

- Raising coverage targets; coverage for live suites.

## Evidence

`@vitest/coverage-v8` 4.1.11 (exact, matching Vitest). `test:coverage` = `npm run test:unit -- --coverage`; coverage includes `src/**/*.ts` minus `src/tests/**`. Baseline 86.29/78.22/87.5/88.05 (statements/branches/functions/lines), stable to 0.03% across 4 runs; thresholds 86/78/87/88. `--coverage.thresholds.lines=89` exits 1 with "Coverage for lines (88.05%) does not meet global threshold (89%)". CI build job runs `test:coverage` in place of `test:unit`. `coverage/` is already git- and Prettier-ignored; `npm pack --dry-run` lists no coverage files. README lists the command. `npm audit`'s two high findings (`brace-expansion` via ESLint, `source-map-js` via Vite) are dev-only and predate this change.
