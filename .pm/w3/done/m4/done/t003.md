## Objective

New exec sessions use the user-approved profile per mode, so the SDK backend can load them.

## Context

- **Blocked until the user records a decision** under the milestone Decision gate; changing exec approval semantics is not an autonomous choice.

## Steps

1. Implement the approved mapping in `src/modes.ts` / `src/muse-exec.ts`.
2. Live test: create a session through the exec backend per affected mode, then load and continue it through the SDK backend.

## Files
