## Objective

Unhandled and misused promises fail `npm run lint`.

## Context

- `eslint.config.js` already parses with type information (`parserOptions.project`), but `tseslint.configs.recommended` does not include the type-checked promise rules.
- Hits on 2026-10-15: `src/index.ts:104` `connection.closed.then(shutdown)` (floating), and `src/index.ts:106-107` `process.on("SIGTERM"|"SIGINT", shutdown)` passing the async `shutdown` (misused). `agent.dispose()` rejections are already caught inside `shutdown`. Also `src/tests/loopback-provider.ts:223` (async `request.on("end")` handler).

## Steps

1. Enable `@typescript-eslint/no-floating-promises` and `@typescript-eslint/no-misused-promises` as errors.
2. Fix each hit by handling rejection explicitly (await, `.catch` with logging, or `void` only where rejection is already handled), preserving shutdown and exit behavior.
3. Evaluate `@typescript-eslint/await-thenable`; enable it only if its hits are zero or trivially fixable.

## Files

- src/index.ts
- src/tests/loopback-provider.ts
