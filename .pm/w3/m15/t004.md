## Objective

Tests that depend on execution order or leaked shared state fail in CI instead of passing by accident.

## Context

- The deterministic suite has 81 files and 506 tests (2026-10-15). Shared module state, environment variables, temporary directories and unrestored fake timers are the likely leak sources.
- Depends on t001 so the known timing flake does not mask order failures.

## Steps

1. Run the deterministic suite with `--sequence.shuffle` and at least 5 explicit `--sequence.seed` values.
2. Fix any order-dependent test at its source; do not pin an order.
3. Add a shuffled run to the CI build job (for example a `test:unit:shuffle` script) that prints its seed so failures reproduce.

## Files

- package.json
- .github/workflows/ci.yml
- src/tests/ (affected tests)

## Acceptance criteria

- [ ] At least 5 distinct seeds pass locally; the seeds are recorded.
- [ ] CI runs a shuffled pass that logs its seed.
- [ ] The CI build job stays within its 10-minute timeout; duration recorded.

## Out of scope

- Shuffling live or real-host suites.
