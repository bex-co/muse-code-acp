# 006 — Computer-use settings and setup

Why: Muse 1.4.4/1.4.6 `computerUseSettings/*` and `computerUseSetup/*` configure macOS computer use, which ACP clients cannot drive.

Deferred from the 2026-10-12 feature research: no natural ACP surface; revisit with a concrete client need. Never change the user's computer-use permissions implicitly.

Re-checked 2026-10-15: there is still no ACP surface for this. The Muse surface has grown: SDK 1.4.7 added `computerUseSetup/check`, and 1.4.8 adds per-app choices (`apps` on read/update, `installedApps`).
