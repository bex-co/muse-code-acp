## Objective

Build the engine primitive: spawn `muse exec --json` with controlled flags, parse its JSONL event stream into typed envelopes, and map process exit to a turn outcome.

## Context

- Verified envelope (muse 0.2.1): `{schema_version, id, stream:{kind,id}, sequence, recorded_at, record_type: event|status|reconciliation, durability, causation_id, payload_type, payload_schema_version, payload}`.
- Payload types to model now: `run.output.delta`, `run.terminal.*`, `turn.input.user`, `task.lifecycle.*`, `tool.result`, `session.run.linked`, `runtime.command.accepted`. Unknown types must pass through as opaque (forward-compat).
- Startup preamble: `muse:`-prefixed diagnostic lines observed before JSONL — determine stdout vs stderr empirically and skip non-JSON lines defensively either way.
- Exit codes: 0 completed, 1 failed/cancelled, 2 usage error, 130/143 signals.
- Spawn shape: `muse exec --json --session-id <uuid> --workspace <cwd> [--no-session-log in tests] [--provider echo in tests] <prompt>`.

## Steps

1. `muse-exec.ts`: `spawnMuseExec(opts)` returning `{events: AsyncIterable<MuseEvent>, kill(), done: Promise<ExitOutcome>}`.
2. Zod schemas for the envelope + known payloads; `schema_version !== 1` → structured warning, opaque passthrough.
3. Line splitter tolerant of partial lines, non-JSON preamble, and interleaved stderr.
4. Record echo-provider fixtures (`muse exec --provider echo --json --no-session-log "…"`) into `src/tests/fixtures/`; parser unit tests run entirely from fixtures.

- [ ] Preamble/garbage lines never throw; they are logged to the file logger only
