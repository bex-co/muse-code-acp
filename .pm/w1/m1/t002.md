## Objective

Bring over the vendor-neutral entry-point layer from `claude-agent-acp`: stream adapters, stdout/stderr discipline, file logging, version flag, and the `--cli` passthrough pattern retargeted at the `muse` binary.

## Context

- `claude-agent-acp/src/utils.ts` (89 lines) — copy verbatim: `nodeToWebReadable/Writable`, `Pushable`, `unreachable`.
- `claude-agent-acp/src/index.ts` (107 lines) — adapt: console redirected to stderr (stdout is the ACP channel), optional file logging via `MUSE_AGENT_LOGS` (rename of `CLAUDE_AGENT_LOGS`), `--version`, and `--cli <args…>` exec-ing the user's `muse` binary (resolved from `PATH` or `MUSE_CODE_EXECUTABLE`) — used later for `muse login`.
- No managed-settings env application at startup (Claude-specific `resolveSettings` call) — drop it.

## Steps

1. Copy `utils.ts`; keep names identical for diff-ability against upstream.
2. Write `index.ts`: arg parse (`--cli`, `--version`, default → `runAcp`), console→stderr redirect, logger setup.
3. Implement `museCliPath()`: `MUSE_CODE_EXECUTABLE` env override, else `PATH` lookup; fail with a clear install hint if absent.
4. Unit-test `museCliPath` resolution and the `--version` path.
